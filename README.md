# Afterglow

Afterglow is a system monitor for Windows 10 and 11 that shows, at a glance, how hard your PC is working. It tracks the CPU, memory, disk, network, GPU and battery in real time on gauges and live graphs. It also reads CPU and GPU temperatures and, where the hardware reports it, power use in watts. Everything runs locally on your computer: no account, no cloud service and no data sent anywhere. Its look takes after the glowing displays of classic hardware, with phosphor-style colors, an optional bloom effect, and dark or light themes.

Beyond the summary dashboard, Afterglow digs into the details. The Performance pages break activity down per processor core, disk, network adapter and graphics engine. The Processes view works like a richer Task Manager: you can search and sort programs, group them by application, see which program started which, and inspect each one’s CPU, memory, disk and GPU use. When something misbehaves, you can end, suspend or resume it. Afterglow checks that it’s acting on the right process and refuses to touch critical system processes.

Afterglow also covers the wider state of your PC. It lists startup programs and scheduled tasks, installed apps, Windows services, live network connections with the programs that own them, power and battery details, and which folders are using the most disk space. A Flight Recorder can capture a session of activity, up to an hour, so you can save it and replay it later to work out what happened during a slowdown. There are also quick built-in benchmarks for the CPU, memory and disk, optional alerts for high temperature, low memory or a runaway process, and a compact mini-window you can keep on screen.

Afterglow installs with a single setup program, which also installs the signed sensor driver needed for CPU temperature and power readings. Setup can launch the app as soon as it finishes. Afterglow asks for administrator permission when it opens, because Windows only gives those readings to admin programs. It also lives in the system tray, showing a live readout of CPU and temperature.
